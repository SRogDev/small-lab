# Decision records

Significant decisions about Small Lab — architecture, methodology,
tooling, research direction — are recorded here as short decision
records, one file per decision, so future work can see *why* something
is the way it is.

A record should state: the decision, the context that forced it, the
options considered, the consequences, and the date. Keep each record
short; a decision nobody can read will not be followed.
